## Curation result / 選定結果

All 63 forks were excluded because no material customization was found. Owned
repositories were excluded when Azure was not central, the repository was empty,
the technology was retired, the repository duplicated a stronger entry, or the
available documentation was insufficient for a reliable learning experience.

63 件の fork は、実質的な独自変更を確認できなかったため、すべて対象外としました。
自有リポジトリについても、Azure が主題でない、空のリポジトリ、廃止済み技術、
より完成度の高い重複コンテンツ、または学習用途として資料が不十分なものは掲載していません。
